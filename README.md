Проект outages
-----------------

Этот репозиторий содержит небольшой инструмент для загрузки и хранения плановых отключений электроэнергии (planned outages) из публичного API Yasno (https://app.yasno.ua/...) и вывода компактного отчёта.

Ключевые возможности:

- Загрузка расписаний из API Yasno и сохранение в локальную SQLite базу `outages.db`.
- Кэширование HTTP-запросов: повторные запросы к API не выполняются чаще, чем раз в 5 минут.
- Вывод времени в формате HH:MM.
- CLI: параметры `--device`, `--date`, `--menu`, `-v/--verbose`.
- По умолчанию група: `28.1`, формат даты по умолчанию `DD.MM.YYYY`.
- Компактный вывод по умолчанию и расширенная отладочная информация под `-v`.
- Нормализация записей в базе: при импорте выполняется объединение дублирующихся записей расписаний по паре `(device_id, schedule_date)`, сохраняется самая свежая запись, а все уникальные временные слоты собираются в единый набор.

Изменения, добавленные в этой сессии:

- Добавлен вызов нормализации расписаний в `save_json_data`.
- Реализована функция `_normalize_schedules(conn)` в `database.py`, которая объединяет дубликаты по `device_id` и `schedule_date` и сохраняет уникальные `time_slots`.
- Исправлена логика сохранения расписаний: теперь расписание ищется и обновляется по сочетанию `device_id + schedule_date`, и лишние строки удаляются.
- Добавлен компактный вывод с объединением 'Definite' слотов в `main.py` (детали и режим отладки доступны через `-v`).

Как запустить:

1. Установите зависимости (используется UV/uv):

```bash
uv add requests
```

2. Запуск скрипта (по умолчанию показывает расписание для `28.1` на сегодня):

```bash
python3 main.py
```

3. Примеры:

- Показать для групи `28.1` на конкретну дату:

```bash
python3 main.py --group 28.1 --date 17.02.2026
```

- Включить подробный вывод:

```bash
python3 main.py -v
```
